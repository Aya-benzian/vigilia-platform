## 3. Features — Sparkov

> Verify all column names by printing `fraudTrain.columns.tolist()` on day 1.

### Raw columns (verify names on real file)

| Column | Type | Role |
|---|---|---|
| `trans_num` | string | **Identifier — dropped, never a feature** |
| `trans_date_trans_time` | datetime | Source for `hour`, `dow`, `is_night` |
| `cc_num` | int64 | **CV group key only — never a feature** |
| `merchant` | string | [NICE] frequency or target encoding |
| `category` | string | One-hot (handle_unknown="ignore") |
| `amt` | float | → `amt_log = log1p(amt)` |
| `first` | string | **Dropped (identifier)** |
| `last` | string | **Dropped (identifier)** |
| `gender` | string | Binary encoded |
| `street` | string | **Dropped (identifier)** |
| `city` | string | [NICE] or dropped |
| `state` | string | [NICE] frequency encoding |
| `zip` | int | Dropped or grouped |
| `lat` | float | Customer latitude → `distance_km` |
| `long` | float | Customer longitude → `distance_km` |
| `city_pop` | int | → `city_pop_log = log1p(city_pop)` |
| `job` | string | [NICE] frequency or target encoding |
| `dob` | date | → `age` (from dob + transaction date) |
| `merch_lat` | float | Merchant latitude → `distance_km` |
| `merch_long` | float | Merchant longitude → `distance_km` |
| `is_fraud` | int (0/1) | **Target variable** |

### Engineered features

| Feature | Formula | Notes |
|---|---|---|
| `amt_log` | `log1p(amt)` | Reduces right skew of transaction amounts |
| `hour` | `trans_datetime.hour` | Transaction hour (0–23) |
| `dow` | `trans_datetime.dayofweek` | Day of week (0=Monday) |
| `is_night` | `1 if hour in [0..5] else 0` | Night-time flag |
| `distance_km` | haversine(lat, long, merch_lat, merch_long) | Physical distance between cardholder and merchant |
| `age` | `(trans_date - dob).days / 365.25` | Cardholder age at time of transaction |
| `city_pop_log` | `log1p(city_pop)` | Reduces right skew of city population |

## 7. Data Splits

Splits are **consecutive in time** (fraudTrain is sorted by date).

| Part | Data | Purpose | Seen by model? |
|---|---|---|---|
| **A** | First 80% of fraudTrain | Tuning + CV comparison + final model fit | Yes (fit on A only) |
| **B** | Next 10% of fraudTrain | Calibrator fit only | No (model never trained on B) |
| **C** | Last 10% of fraudTrain | Threshold selection on calibrated probabilities | No |
| **fraudTest** | All of fraudTest | One-time final evaluation — used ONCE at the very end | No |

**Rules:**
- Tuning subsample and comparison subsample are disjoint subsets of A.
- Resampling (if any) only inside training folds, never on the full A.
- All preprocessing fitted inside the Pipeline inside each fold.
- Seed = 42 everywhere, logged in MLflow.

## 10. Known Limitations

- Sparkov is **synthetic** — high scores do not prove real-world performance.
- Stratified CV mixes time periods (slightly optimistic). Final test is temporal to compensate.
- **Customer fingerprint:** the model may partly memorize customers. Both stratified and grouped CV are run and reported.
- ULB benchmark only checks that model **ranking** holds — never used for final model selection.
